# Team Roles & Responsibilities

- **Lead Fullstack Engineer**: Orchestrates API contracts, state lifecycle, and deployment pipeline.
- **NLP / Backend Specialist**: Implements date normalizers, LLM extraction prompts, regex engines, and conflict detection heuristics.
- **Frontend / UI Designer**: Crafts responsive, accessible, dark/light modern UI with micro-interactions and timeline visualizations.
- **Legal QA & Domain Consultant**: Validates sample legal texts, procedural rules, and ensures audit trail standards.
